Field data

Lizards were captured in three censuses. Only in spring 2024 were lizards measured, performance-tested and marked. The fall 2024 census (6 months later) recorded only captures. Spring 2025 (12 months) is available only as a resighted/not-resighted record for each marked lizard.

The analysis uses the three focal species. Two other species were also marked but cannot support the analysis:

  • A. distichus (16 lizards) had only 2 survivors.
  • A. equestris (11 lizards) has no sprint or bite data. It is also far larger (SVL 116–149 mm) than the focal species (about 40–65 mm).

The cleaned dataset, data/lizards-spring-2024.csv, has one row for each of the 734 focal-species lizards marked in spring 2024. It is produced from the raw field data by R/process-raw-data.R.

Morphology

Raw linear measurements mostly measure body size. Within each species, every raw trait correlates strongly with snout–vent length (SVL). We therefore separate size, measured as log SVL, from shape, measured as size-corrected traits. Shape is the log trait minus log SVL, or minus 2 × log SVL for areas.

The predictors used in the model are body size plus one size-corrected shape trait for each performance trait. Each shape trait was chosen a priori from anole functional morphology:

Predictor Definition Linked performance trait
size \(\log \text{SVL}\) all four
relative hindlimb \(\log \text{hindlimb} - \log \text{SVL}\) sprint speed
relative head width \(\log \text{head width} - \log \text{SVL}\) bite force
relative hind toe length \(\log \text{hind toe} - \log \text{SVL}\) clinging on bark (stand-in for claw size)
relative toepad area \(\log(\text{fore} + \text{hind toepad area}) - 2 \log \text{SVL}\) clinging on leaves

The reasons for these choices:

  • Composite limb lengths. forelimb and hindlimb are exact sums of their upper and lower segments, so segments and totals cannot be included together.
  • Head length is dropped. In A. carolinensis (\(n = 47\)), relative head length correlates strongly with relative head width and with SVL. With so few lizards, both head traits could not be separated.
  • Claws. Clinging to rough bark relies mainly on claws, and clinging to smooth leaves on adhesive toepads. Claws were not measured, so relative hind toe length stands in for claw size.
  • Toepads. Fore and hind toepad areas are summed into a single total.
  • Implausibly short hind toes. Twelve hind toe lengths were implausibly short, for example 1.0–3.9 mm in lizards of about 43 mm SVL whose toes are typically about 7 mm. They are set to missing when the robust within-species \(z\)-score (median and MAD) of log hind toe − log SVL is below −5. The values show a clear gap: flagged lizards lie between −7.4 and −37, and the next lowest is −4.0.
  • No PCA. With one or two predictors per performance trait there is no dimensionality problem to solve. Principal components would also mix size and shape back together, and their loadings, and so their meaning, would differ among species.

Some features of these distributions shape the model:

  • Leaf-clinging zeros. 22 lizards scored 0 on leaves. The smallest non-zero value is 0.01, the resolution of the instrument, so a zero means “below 0.01” rather than no clinging at all. The model treats these values as left-censored, estimating each somewhere below the limit.
  • Why not log(x + 1). The common alternative of adding a constant before taking logs does not work here. For values this small, log(x + 1) is nearly the raw value (correlation 0.996), and the skew barely changes: 4.4 raw and 3.5 after the transform, compared with 0.8 for log of the non-zero values. Results would also depend on the arbitrary constant.
  • Sprint speed has a heavy lower tail. 8 lizards are more than 3 SD below their species × sex mean, down to 9.7 cm/s. These are probably trials where the lizard did not run properly. The model currently uses normal residuals; heavier-tailed (Student-t) residuals are a possible extension.
  • Sprint speed is coarsely measured. There are only 29 distinct sprint values, consistent with a fixed track length timed in coarse steps. Near 150 cm/s this is about ±10% rounding.

Within species and sex, sprint speed increases with temperature (pooled slope 0.15 SD per °C). Bite force increases clearly only in A. carolinensis. Temperature therefore enters the model as a predictor of sprint and bite. Over this narrow range of temperatures a linear effect is adequate.

Survival and resighting

Each lizard has a resighting history: whether it was seen in fall 2024 (\(y_2\)) and whether it was seen in spring 2025 (\(y_3\)). The recorded “6-month survival” is 1 if the lizard was seen at either census. It therefore counts a lizard that was alive but never seen again as dead.

Show code 
analysis |>
  mutate(history = paste0(seen_fall, surv_12m)) |>
  count(species, history) |>
  pivot_wider(names_from = history, values_from = n, values_fill = 0) |>
  mutate(
    `naive 6-month survival` = sprintf("%.2f", (`01` + `10` + `11`) / (`00` + `01` + `10` + `11`)),
    `fall miss rate` = sprintf("%d/%d = %.2f", `01`, `01` + `11`, `01` / (`01` + `11`))
  ) |>
  select(species, `00`, `01`, `10`, `11`, `naive 6-month survival`, `fall miss rate`) |>
  knitr::kable()

Live lizards are often missed in fall, and A. carolinensis is missed more often than it is seen. Species differences in naive survival therefore partly reflect how easy each species is to find. The model estimates fall detection jointly with survival, using lizards seen in spring 2025 but missed in fall.

```{r}
#| label: performance-numbers
leaf <- analysis$cling_leaf[!is.na(analysis$cling_leaf)]
skew <- function(v) mean((v - mean(v))^3) / sd(v)^3
sprint_z <- analysis |>
  filter(!is.na(sprint)) |>
  group_by(species, sex) |>
  mutate(z = (log(sprint) - mean(log(sprint))) / sd(log(sprint))) |>
  ungroup()
```

Some features of these distributions shape the model:

- **Leaf-clinging zeros.** `r sum(leaf == 0)` lizards scored 0 on
  leaves. The smallest non-zero value is 0.01, the resolution of the
  instrument, so a zero means "below 0.01" rather than no clinging at
  all. The model treats these values as left-censored, estimating each
  somewhere below the limit.
- **Why not log(x + 1).** The common alternative of adding a constant
  before taking logs does not work here. For values this small,
  log(x + 1) is nearly the raw value (correlation
  `r round(cor(leaf, log(leaf + 1)), 3)`), and the skew barely changes:
  `r round(skew(leaf), 1)` raw and `r round(skew(log(leaf + 1)), 1)`
  after the transform, compared with `r round(skew(log(leaf[leaf > 0])), 1)`
  for log of the non-zero values. Results would also depend on the
  arbitrary constant.
- **Sprint speed has a heavy lower tail.**
  `r sum(sprint_z$z < -3)` lizards are more than 3 SD below their
  species × sex mean, down to `r round(min(analysis$sprint, na.rm = TRUE), 1)` cm/s.
  These are probably trials where the lizard did not run properly. The
  model currently uses normal residuals; heavier-tailed (Student-t)
  residuals are a possible extension.
- **Sprint speed is coarsely measured.** There are only
  `r n_distinct(na.omit(analysis$sprint))` distinct sprint values,
  consistent with a fixed track length timed in coarse steps. Near
  150 cm/s this is about ±10% rounding.

Within species and sex, sprint speed increases with temperature (pooled

adequate.

## Survival and resighting

Each lizard has a resighting history: whether it was seen in fall 2024
($y_2$) and whether it was seen in spring 2025 ($y_3$). The recorded
"6-month survival" is 1 if the lizard was seen at either census. It
therefore counts a lizard that was alive but never seen again as dead.

```{r}
#| label: tbl-histories
#| tbl-cap: "Resighting histories ($y_2 y_3$: 1 = seen) and the naive fall miss rate among lizards known to be alive in fall because they were seen in spring 2025."
analysis |>
  mutate(history = paste0(seen_fall, surv_12m)) |>
  count(species, history) |>
  pivot_wider(names_from = history, values_from = n, values_fill = 0) |>
  mutate(
    `naive 6-month survival` = sprintf("%.2f", (`01` + `10` + `11`) / (`00` + `01` + `10` + `11`)),
    `fall miss rate` = sprintf("%d/%d = %.2f", `01`, `01` + `11`, `01` / (`01` + `11`))
  ) |>
  select(species, `00`, `01`, `10`, `11`, `naive 6-month survival`, `fall miss rate`) |>
  knitr::kable()
```

Live lizards are often missed in fall, and *A. carolinensis* is missed
more often than it is seen. Species differences in naive survival
therefore partly reflect how easy each species is to find. The model
estimates fall detection jointly with survival, using lizards seen in
spring 2025 but missed in fall.
