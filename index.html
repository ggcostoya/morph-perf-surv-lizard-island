Start here

Does morphology affect survival only through performance?

This site is the complete, open record of a study of natural selection in three Anolis lizards on Lizard Island. Every step is here, from the cleaned field data to the final biological conclusions: data cleaning decisions, model equations, Stan code, validation and model checks. The pages are meant to be read in order, but each one stands on its own.

The question

Many evolutionary studies link morphology directly to survival or reproductive success. The ecomorphological paradigm proposes a middle step instead: morphology determines what an animal can do, its whole-organism performance, and performance determines whether it survives.

We test two hypotheses:

  • M1, full mediation. Morphology affects 6-month survival only through sprint speed, bite force and clinging ability on bark and on leaves.
  • M2, partial mediation. Morphology also affects survival directly, through routes that measured performance does not capture.

Study system

Lizards were captured, measured, tested for performance and individually marked in spring 2024, then resighted in fall 2024 (6 months) and spring 2025 (12 months). We analyse three species that share the island:

Species Abbreviation
Anolis carolinensis caro
Anolis cristatellus cris
Anolis sagrei sag

Survival is never observed directly, only resightings. Lizards that are alive can be missed, and how often differs among species. The model therefore estimates detection probability alongside survival.

Reproducing the analysis

The repository contains everything needed to reproduce the results from the cleaned data:

data/        cleaned analysis dataset and capture summary
R/           shared functions: data preparation, priors, simulator, plot theme
stan/        Stan model (in progress)
scripts/     long computations (SBC, model fits), saved to results/
figures/     static figures (causal diagram)
*.qmd        the pages of this site

To rebuild the site, clone the repository, install the R packages loaded in R/ and the pages, and run quarto render. Heavy computations (simulation-based calibration and model fits) are run separately from scripts/, and their saved outputs are read by the pages.

Data availability

The analysis uses data/lizards-spring-2024.csv, which has one row per lizard marked in spring 2024. It includes every correction and exclusion as columns (corrections, exclusion), so each cleaning decision on the Data page can be traced. The raw field data are not part of the public repository. The cleaned file is produced from them by R/process-raw-data.R, which is included so that every cleaning step is documented.
